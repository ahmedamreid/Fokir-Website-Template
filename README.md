# Fokir Website Template

A responsive portfolio landing page template with sections for About, Services, Portfolio, Testimonials, Blog, and Contact.

Base template by Theme-fair, adapted and practiced with here. Content (name, bio, projects) is currently placeholder text — swap in real content before using as a live portfolio.

## Tech Stack

- HTML5 / CSS3
- Google Fonts / Material Symbols
- Font Awesome icons

## Getting Started

This is a static site with no build step. Open `index.html` directly in a browser, or serve the folder with any static file server:

```bash
npx serve .
```
